================================================================================
  App Inbox Binary Protocol — All Four Notification Shapes
================================================================================

  Decision tree:
    targetId NEGATIVE → personalisations follow
    targetId POSITIVE → no personalisations
    epoch NEGATIVE    → variant byte follows
    epoch POSITIVE    → no variant

  Per-personalisation entry (always same structure):
    [propId: 2 bytes unsigned short] [valueLen: 1 byte] [value: valueLen bytes UTF-8]

  SHAPE B — Has variant, No personalisations (9 bytes)

  SIZE SUMMARY
================================================================================

  Shape  Variant  Pers   Min bytes  Formula
  -----  -------  ----   ---------  -------
  A      No       No     8          4 (targetId) + 4 (epoch)
  B      Yes      No     9          4 + 4 + 1 (variant)

  Hard limits:
    Max buffer size:                  10,000 bytes (all notifications combined)
    Max personalisations per notif:   255 (1 byte count)
    Max value length per pers:        255 bytes (1 byte valueLen)
    Max propId:                       65,535 (2 byte unsigned short)
    Max variant:                      255 (1 byte)
    Max targetId:                     2,147,483,647 (int31, sign bit used)
    Max epoch:                        2,147,483,647 (Year 2038 problem!)


================================================================================
  SIGN BIT QUICK REFERENCE
================================================================================

  targetId:
    POSITIVE (MSB=0) → no personalisations
    NEGATIVE (MSB=1) → personalisations block follows
    Real value: Math.abs(targetId)

  epoch:
    POSITIVE (MSB=0) → no variant
    NEGATIVE (MSB=1) → 1-byte variant follows
    Real value: Math.abs(epoch)

  Encoding (Notification.java:252-258):
    Utils.encodeInt(hasPersonalisations ? -targetId : targetId, ...)
    Utils.encodeInt(hasVariant ? -epoch : epoch, ...)

  Decoding (Notification.java:444-458):
    int targetIdFromStorage = Utils.decodeInt(b, start)  // raw, may be negative
    int targetId = Math.abs(targetIdFromStorage)          // real value
    if (targetIdFromStorage < 0) → read personalisations
    if (epochFromStorage < 0) → read variant
